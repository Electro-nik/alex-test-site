# LAN HUB — сайт на Flask для локальної мережі

Адаптивний сайт з чатом, голосуванням, реакціями, підрахунком активних пристроїв та збереженням у SQLite. Інтерфейс оновлюється приблизно кожні 2,5 секунди. Зовнішні CDN не потрібні.

## Запуск на Windows

1. Установи Python 3, якщо його ще немає.
2. Розпакуй ZIP та відкрий папку `lan_hub`.
3. Двічі клацни `start_windows.bat`. Він створить `.venv`, встановить Flask і запустить сайт.
4. У браузері комп'ютера відкрий `http://127.0.0.1:5000`.

Можна й вручну з PowerShell (з папки проєкту):

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## Як зайти з телефона

1. Телефон і комп'ютер мають бути підключені до однієї Wi-Fi/LAN мережі. Вимкни на телефоні VPN, якщо він заважає локальній мережі.
2. На комп'ютері натисни `Win + R`, введи `cmd`, потім команду `ipconfig`.
3. Знайди `IPv4 Address` Wi-Fi або Ethernet, наприклад `192.168.1.105`.
4. На телефоні відкрий `http://192.168.1.105:5000` (підстав свій IP).
5. Якщо Windows запитає доступ для Python, дозволь **Private networks**. Якщо не працює — перевір правила брандмауера Windows для вхідного TCP-порту `5000`, а також чи на роутері не ввімкнено Wi-Fi client isolation / guest network.

Не відкривай у телефоні `http://0.0.0.0:5000` або `http://127.0.0.1:5000` — використовуй IP **комп'ютера**.

## Як це працює

- `app.py` — Flask-сервер і API: `GET /api/state`, `POST /api/message`, `POST /api/vote`, `POST /api/reaction`, `POST /api/ping`.
- `templates/index.html` — структура сайту.
- `static/style.css` — дизайн і адаптація до телефона.
- `static/app.js` — запити до Flask, оновлення чату, голосування й реакцій.
- `lanhub.db` — SQLite-база; створиться під час першого запуску.

## Безпека

Це **навчальний проєкт лише для довіреної локальної мережі**: авторизації та складного захисту від спаму немає. Не відкривай порт `5000` у роутері для доступу з Інтернету. Flask запущено з `debug=False`, однак вбудований сервер призначений для розробки, а не production.
